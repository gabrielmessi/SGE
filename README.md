# Controle de Estoque

Sistema web para gerenciamento de estoque de uma adega, desenvolvido para praticar e aplicar conhecimentos de **HTML, CSS e JavaScript**.

# Sobre o projeto

# O SGE — Sistema de Gestão de Estoque, é uma aplicação que permite cadastrar produtos, acompanhar quantidades disponíveis e registrar movimentações de estoque. O projeto também conta com recursos de controle financeiro diário e acompanhamento do caixa.

# Funcionalidades

- **Cadastro de produtos:** adicionar e editar produtos, categorias, preços e quantidades.
- **Controle de estoque:** acompanhar o estoque atual e definir quantidades mínimas.
- **Movimentações:** registrar entradas, saídas e perdas de produtos.
- **Pesquisa e filtros:** localizar produtos por nome, categoria ou situação do estoque.
- **Histórico:** consultar movimentações registradas.
- **Controle financeiro diário:** acompanhar vendas, compras, perdas e despesas.
- **Controle de caixa:** registrar o valor inicial, conferir o saldo esperado e informar o valor final.
- **Armazenamento local:** salvar os dados no navegador utilizando `localStorage`.

# Tecnologias utilizadas

- **HTML5** — estrutura da aplicação.
- **CSS3** — estilização e organização visual.
- **JavaScript** — funcionalidades, cálculos e manipulação dos dados.
- **LocalStorage** — persistência dos dados no navegador.

# Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Não é necessário configurar um servidor ou banco de dados para executar a versão local.

# Estrutura do projeto

```text
adega-controle-estoque/
├── index.html
├── styles.css
└── script.js
```

# Observações

- Os dados ficam armazenados no navegador utilizado.
- Limpar os dados do navegador pode apagar as informações salvas.
- Esta versão utiliza armazenamento local, não um banco de dados compartilhado entre diferentes dispositivos.
